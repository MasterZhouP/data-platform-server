## 实施决定

- 平台配置使用 MySQL，遵循基线；不采用本地文件替代配置数据库。
- 初始 SQL 与元数据可以离线配置保存；未启用 U8 时，查询/自动探测明确失败，不在生产代码伪造业务行。上线前必须真实核对元数据。
- 参照接口采用独立服务认证安全链，管理接口继续使用若依用户权限。
- 首条物料参照实现与 OA 插件开发解耦；字段映射仍由 OA 插件配置。
- 本轮改动以业务代码、配置和迁移脚本交付；不把尚未进行的真实数据库/插件联调计为通过。
